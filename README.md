# Share a Meal — Food Donation Frontend

A responsive frontend website concept for a food donation system. It demonstrates how event organizers, households, NGOs, and volunteers could coordinate surplus food donations.

## Features

- Responsive landing page and mobile navigation
- Food donation form with required-field validation
- JavaScript-generated donation cards
- Sample food donation listings
- Accessible form status messages and semantic HTML
- No framework or installation required

## Built with

- HTML5
- CSS3
- Vanilla JavaScript

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a browser.
3. Fill in the donation form to add a demo listing.

## Upload to GitHub

1. Sign in at [GitHub](https://github.com/).
2. Create a new repository named `food-donation-frontend`.
3. Choose Public or Private and create the repository.
4. Click **Add file → Upload files**.
5. Upload `index.html`, `style.css`, `script.js`, and `README.md`.
6. Click **Commit changes**.

## Publish with GitHub Pages

1. Open the repository's **Settings**.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.
5. Wait for the deployment to finish; GitHub will show the published website URL in the Pages section.

## Important demo limitation

This is a frontend-only student project. Donation listings are added to the page in the current browser session only. The form does not send information to an NGO or save it to a database. Real-world food donation coordination would need a backend, persistent storage, authentication, and food-safety procedures.
